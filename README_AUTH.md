# 인증 시스템 설정 가이드

어드민 페이지는 간단한 4자리 비밀번호로 보호됩니다.

## 비밀번호 설정

비밀번호는 `lib/auth.ts` 파일에서 설정할 수 있습니다:

```typescript
const ADMIN_PASSWORD = "1234"; // 원하는 4자리 숫자로 변경
```

**기본 비밀번호**: `1234`

## 사용 방법

### 1. 로그인
1. 브라우저에서 `/admin/login` 접속
2. 4자리 비밀번호 입력 (기본값: `1234`)
3. 로그인 성공 시 `/admin/upload`로 자동 이동

### 2. 로그아웃
- 어드민 페이지 우측 상단의 "로그아웃" 버튼 클릭

## 세션 관리

- 로그인 상태는 localStorage에 저장됩니다
- 세션 유지 시간: 24시간
- 24시간 후 자동으로 로그아웃됩니다

## 보안 참고사항

⚠️ **주의**: 이 인증 방식은 간단한 보호 목적입니다.

- 비밀번호는 코드에 하드코딩되어 있어, 코드를 볼 수 있는 사람은 비밀번호를 알 수 있습니다
- 프로덕션 환경에서는 더 강력한 인증 시스템(Supabase Auth, NextAuth 등) 사용을 권장합니다
- 현재는 클라이언트 사이드에서만 보호되므로, 서버 사이드 보호가 필요하면 추가 설정이 필요합니다

## 비밀번호 변경 방법

1. `lib/auth.ts` 파일 열기
2. `ADMIN_PASSWORD` 값을 원하는 4자리 숫자로 변경
3. 저장 후 재배포

```typescript
// 예시: 비밀번호를 5678로 변경
const ADMIN_PASSWORD = "5678";
```
